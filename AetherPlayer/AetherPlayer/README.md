# Aether Player v1.0 (cast diagnostics: tap "Log" in the app)
Kotlin + Jetpack Compose + Media3 + Google Cast.

Home (recently added / played / most played) · Library (songs/albums/artists) · Folders · Playlists (create, import/export .m3u)
Queue · shuffle/repeat · speed · sleep timer · EQ (presets, bass boost) · gapless · artwork (1024px on lock screen/notification)
Lyrics (.lrc next to songs + embedded MP3/FLAC/M4A, synced, tap to seek) · Chromecast/Nest casting of the original file (FLAC included)

Lyrics from .lrc files need "All files access" (button in the Lyrics tab).
Casting: phone and cast device on the same Wi-Fi.

Build: push to GitHub -> Actions -> "Build APK" -> download artifact. Or Android Studio -> Build APK.
